# Top Chef project routing

This repository is the FastAPI system and its bundled admin/cashier UI. The sibling `../menu` repository is the public customer site. For work that may affect either side, read [the project skill](.agents/skills/top-chef-system/SKILL.md) and only the reference it routes to. Check the other repository's current state before changing a shared API contract.

The project skill is a source map, not proof that deployed code, remote schema, or live configuration matches this checkout. Verify those boundaries for the task at hand. Preserve unrelated changes and avoid reading or printing `.env` during discovery.
